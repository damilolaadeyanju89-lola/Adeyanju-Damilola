# Damilola Adeyanju Portfolio

An interactive portfolio for Damilola Adeyanju, built with React, TypeScript,
GSAP, and Three.js.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

The Vite app, source code, public assets, and configuration files all live at
the repository root. The `/works` path displays the additional projects page.
